# 沙盒模式小动物分类分析

## 分类逻辑

沙盒模式下，小动物的第一层分类是根据 **species 标签** 进行分类的。具体实现如下：

1. **分类依据**：每个小动物都有一个 `species` 标签，相同 `species` 的小动物会被分到同一个分类中。
2. **分类实现**：在 `SandboxToolParameterMenu.cs` 中，通过遍历所有带有 `GameTags.CreatureBrain` 标签的预制体，获取每个小动物的 `species` 标签，然后根据这个标签进行分组。
3. **分类名称**：分类名称是通过 `Strings.Get("STRINGS.CREATURES.FAMILY_PLURAL." + brain.species.ToString().ToUpper())` 来获取的。

## 畸变体分类名称缺失问题

### 问题现象
- 两个畸变体（Sweetle 和 Grubgrub）被分到同一个分类中（符合预期）
- 分类名称缺失（不符合预期）

### 问题原因
1. **Species 标签**：两个畸变体都使用同一个 species 标签 `GameTags.Creatures.Species.DivergentSpecies`
2. **标签字符串表示**：这个标签的字符串表示是 "DivergentSpecies"
3. **名称查找逻辑**：当系统尝试获取分类名称时，会将 "DivergentSpecies" 转换为大写 "DIVERGENTSPECIES"，然后查找 `STRINGS.CREATURES.FAMILY_PLURAL.DIVERGENTSPECIES`
4. **字段定义**：在 `CREATURES.FAMILY_PLURAL` 中，对应的字段是 `DIVERGENTSPECIES`，其值是 "Divergents"，这个定义是正确的

### 技术细节

#### 分类创建代码
```csharp
SandboxToolParameterMenu.SelectorValue.SearchFilter searchFilter = new SandboxToolParameterMenu.SelectorValue.SearchFilter(
    (string) Strings.Get("STRINGS.CREATURES.FAMILY_PLURAL." + brain.species.ToString().ToUpper()),
    (Func<object, bool>) (entity =>
    {
        CreatureBrain component = Assets.GetPrefab((entity as KPrefabID).PrefabID()).GetComponent<CreatureBrain>();
        return (entity as KPrefabID).HasTag(GameTags.CreatureBrain) && component.species == brain.species;
    }),
    parentFilter1,
    icon
);
```

#### 畸变体 Species 标签设置
```csharp
EntityTemplates.AddCreatureBrain(placedEntity, chore_table, GameTags.Creatures.Species.DivergentSpecies, symbolOverridePrefix);
```

#### GameTags 定义
```csharp
public static readonly Tag DivergentSpecies = TagManager.Create(nameof (DivergentSpecies), (string) CREATURES.FAMILY_PLURAL.DIVERGENTSPECIES);
```

## 解决方案

要解决分类名称缺失的问题，建议检查以下几点：

1. **检查 GameTags 定义**：确认 `GameTags.Creatures.Species.DivergentSpecies` 的字符串表示是否正确
2. **检查字符串转换**：确保 `brain.species.ToString().ToUpper()` 的结果与 `CREATURES.FAMILY_PLURAL` 中的字段名完全匹配
3. **手动添加缺失的字符串**：如果是字符串定义缺失，可以在 `CREATURES.FAMILY_PLURAL` 中添加对应的字段

## 结论

- 分类逻辑是正确的，两个畸变体被分到同一个分类中是符合预期的
- 分类名称缺失的问题可能是由于 `brain.species.ToString()` 的结果与预期不符，导致无法正确查找到对应的字符串定义
