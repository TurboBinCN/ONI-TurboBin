# 攻击状态组重新设计方案

## 设计前提
1. 状态机逻辑依赖于畸变体的理智值进行转换
2. 只有攻击状态组表现出攻击相关行为
3. 攻击状态组应包含完整的攻击行为周期
4. 理智值回复后才会退出攻击状态组

## 攻击状态组子状态设计

### 核心状态结构
```
AttackStates (攻击状态组)
├── scanning (目标扫描)
├── chasing (追逐目标)
├── attacking (执行攻击)
├── recovering (攻击后恢复)
├── cooldown (技能冷却)
├── wandering (无目标游荡)
├── retreating (撤退逃跑)
└── staggering (受击硬直)
```

### 状态详细说明

#### scanning (目标扫描)
- **功能**：扫描周围环境寻找潜在目标
- **行为**：
  - 360度扫描周围区域
  - 评估潜在威胁
  - 建立目标优先级列表
- **转换**：
  - 找到目标 → chasing
  - 未找到目标 → wandering
  - 理智值回复 → 退出攻击状态组
  - 受到攻击 → staggering

#### chasing (追逐目标)
- **功能**：追逐选定的目标
- **行为**：
  - 路径规划
  - 移动接近目标
  - 持续更新目标位置
- **转换**：
  - 到达攻击范围 → attacking
  - 目标丢失 → scanning
  - 目标死亡 → scanning
  - 理智值回复 → 退出攻击状态组
  - 受到攻击 → staggering
  - 生命值过低 → retreating

#### attacking (执行攻击)
- **功能**：执行具体的攻击动作
- **行为**：
  - 选择攻击类型
  - 播放攻击动画
  - 执行伤害计算
- **转换**：
  - 攻击完成 → recovering
  - 技能需要冷却 → cooldown
  - 目标死亡 → scanning
  - 理智值回复 → 退出攻击状态组
  - 受到攻击 → staggering
  - 生命值过低 → retreating

#### recovering (攻击后恢复)
- **功能**：攻击后的短暂恢复
- **行为**：
  - 播放恢复动画
  - 重置攻击参数
  - 重新评估目标状态
- **转换**：
  - 恢复完成 → scanning
  - 理智值回复 → 退出攻击状态组
  - 受到攻击 → staggering

#### cooldown (技能冷却)
- **功能**：等待技能冷却完成
- **行为**：
  - 显示冷却效果
  - 计算冷却时间
  - 监控周围环境
- **转换**：
  - 冷却完成 → scanning
  - 理智值回复 → 退出攻击状态组
  - 受到攻击 → staggering
  - 生命值过低 → retreating

#### wandering (无目标游荡)
- **功能**：无目标时的行为
- **行为**：
  - 随机移动
  - 探索周围环境
  - 持续扫描寻找目标
- **转换**：
  - 发现目标 → scanning
  - 理智值回复 → 退出攻击状态组
  - 受到攻击 → staggering
  - 生命值过低 → retreating

#### retreating (撤退逃跑)
- **功能**：生命值过低时的撤退行为
- **行为**：
  - 远离威胁
  - 寻找安全区域
  - 尝试恢复生命值
- **转换**：
  - 生命值恢复 → scanning
  - 理智值回复 → 退出攻击状态组
  - 受到攻击 → staggering

#### staggering (受击硬直)
- **功能**：处理被攻击时的硬直效果
- **行为**：
  - 播放硬直动画
  - 暂时停止所有动作
  - 评估受到的伤害
- **转换**：
  - 硬直结束 → 回到之前的状态
  - 生命值过低 → retreating
  - 理智值回复 → 退出攻击状态组

### 状态转换流程图

```
scanning → (找到目标) → chasing → (到达攻击范围) → attacking → (攻击完成) → recovering → scanning
          ↓ (未找到目标)              ↓ (目标丢失)         ↓ (需要冷却)
          ↓                          ↓                    ↓
      wandering ←←←←←←←←←←←←←←←←←← cooldown
          ↑                          ↑
          ↑ (受到攻击)                ↑ (受到攻击)
          ↓                          ↓
      staggering → (硬直结束) → (回到之前状态)
          ↑
          ↑ (生命值过低)
          ↓
      retreating → (生命值恢复) → scanning
```

### 理智值影响
- **高理智值**：
  - 延长在 wandering 状态的时间
  - 增加 retreating 的触发几率
  - 加快退出攻击状态组的速度
- **低理智值**：
  - 减少在 wandering 状态的时间
  - 增加 attacking 的频率
  - 延迟退出攻击状态组的时间

### 生命值影响
- **高生命值**：
  - 减少 retreating 的触发几率
  - 增加 attacking 的持续时间
- **低生命值**：
  - 增加 retreating 的触发几率
  - 减少 chasing 的距离

## 实现注意事项
1. **状态转换平衡**：确保状态转换逻辑合理，避免状态振荡
2. **性能优化**：目标扫描和路径计算需要合理控制频率
3. **动画配合**：为每个状态设计相应的动画效果
4. **测试**：需要充分测试各种情况下的行为表现
5. **边缘情况处理**：如目标突然消失、环境变化等情况

3. 实现状态转换条件
4. 添加必要的辅助方法和属性
