# 畸变体战斗系统 - 整体架构设计方案

## 一、核心定位

- 轻量、模块化、主被动统一的战斗系统
- 面向：畸变体怪物 / Boss / 特殊单位
- 核心思想：技能 = 触发器 + 效果逻辑 + 表现
- 由上层战斗调度器统一控制时序与阻塞

## 二、模块划分与职责

### 1. 畸变体战斗组件（总调度层）- MutanterCombatManager

- 地位：战斗唯一中央控制器
- 职责：
  - 统一管理并调度【技能组件】与【基础攻击组件】
  - 维护战斗状态：空闲 / 攻击 / 技能释放 / 受击 / 硬直 / 死亡
  - 实现攻击阻塞、动画阻塞
  - 保证普攻与技能不会同时执行、动画不会冲突
  - 处理技能优先级、打断规则、霸体判断（扩展点）
  - 最终决定战斗流程：触发 → 执行 → 收尾
  - 提供动画协调器，管理技能动画播放
  - 管理技能执行队列，确保被动技能有序执行
  - 与攻击策略管理器协作，选择合适的攻击策略
  - 处理状态机锁定与解锁，确保技能执行不被打断
  - 检查技能冷却状态，提供技能就绪判断

### 2. 攻击策略管理器 - AttackStrategyManager

- 地位：攻击策略的管理中心
- 职责：
  - 管理不同类型的攻击策略（技能攻击、基础攻击）
  - 配置各攻击策略的启用状态和优先级
  - 提供策略执行判断逻辑
  - 与战斗管理器协作，选择最佳攻击策略
  - 支持策略的动态启用和禁用
  - 提供策略执行的优先级管理

### 3. 畸变体状态机 - MutanterStateMachine

- 地位：畸变体行为的核心控制器
- 职责：
  - 管理畸变体的各种状态：稳定、焦躁、敌对、攻击等
  - 实现攻击状态组，包括追逐、攻击、冷却、撤退、硬直等子状态
  - 与情绪监控系统集成，根据理智值进行状态转换
  - 与战斗系统集成，触发攻击行为
  - 处理状态机锁定，确保技能执行不被打断
  - 实现目标扫描和追逐逻辑
  - 处理受击硬直和撤退逻辑
  - 管理攻击后的状态转换

### 4. 畸变体技能组件（核心技能层）- MutanterSkillComponent

- 地位：所有主动 / 被动技能的载体与工厂
- 核心设计：技能组装模式
- 一个技能由三部分配置组合而成：
  - 触发器（条件判断）
  - 效果逻辑（伤害、反伤、锁血、Buff 等）
  - 表现层（基础动画组 + 特效组）

#### 4.1 主动技能

- 触发器示例：距离触发、血量区间触发、玩家进入区域、周期触发
- 执行规则：
  - 同类触发器统一批量判定
  - 不同触发器按顺序执行
  - 同一时间只允许一个技能生效（由战斗组件阻塞控制）
- 触发流程：
  - 触发器检测条件（距离、血量区间、玩家进入区域、周期触发等）
  - 触发器Trigger归一判断执行条件满足 → 触发技能选择逻辑（按优先级选择） 返回技能ID
  - SkillComponent → 执行技能（包含效果逻辑和表现层）

#### 4.2 被动技能

- 结构与主动技能完全一致，仅触发来源不同
- 触发器示例：生命值阈值、受到攻击、压力值变化、死亡前
- 效果示例：锁血、反伤、护盾、自爆、召唤、狂暴
- 优势：一套逻辑支持主被动，代码复用极高
- 触发流程：
  - 触发器检测条件（生命值阈值、受到攻击、压力值变化、死亡前等）
  - 触发器Trigger执行条件满足 → 触发调用CombatManager执行
  - CombatManager执行技能（包含效果逻辑和表现层）

#### 4.3 技能统一执行流程

- 触发器检测条件
- 条件满足 → 向战斗组件申请执行权限
- 获得权限 → 应用攻击 / 效果（交给基础攻击组件）
- 同步播放动画 + 特效
- 执行完毕 → 释放状态，恢复可攻击

### 5. 基础攻击组件（数值与状态层）- MutanterAttackSystem

- 地位：纯逻辑运算层，与表现完全剥离
- 职责：
  - 处理伤害类型映射：
    - 扣减生命 / 增加压力值 / 破甲 / 真实伤害等
  - 统一伤害运算入口
  - 应用 Buff / Debuff
  - 处理反伤、吸血、护盾抵消等派生效果
  - 为技能组件提供 "效果执行" 的原子接口
  - 管理攻击行为（MeleeAttack、PsychologicalAttack、SoulAttack 等）

### 6. 触发器系统 - SkillTriggerManager

- 地位：技能触发逻辑的管理中心
- 职责：
  - 注册和管理所有触发器
  - 执行主动触发器的技能选择逻辑
  - 执行被动触发器的逻辑
  - 按优先级排序触发器

### 7. 效果系统 - SkillEffectorManager

- 地位：技能效果的管理中心
- 职责：
  - 注册和管理所有技能效果
  - 加载被动技能效果
  - 应用技能效果（前置和后置）

### 8. 特效系统 - VFXManager

- 地位：技能视觉表现的管理中心
- 职责：
  - 注册和管理所有VFX控制器
  - 提供VFX控制器的获取接口
  - 与技能系统集成，实现技能特效的激活和停用

### 9. VFX控制器 - IVFXController

- 地位：特效的具体实现
- 职责：
  - 管理特效的激活和停用
  - 提供攻击目标检测（AOE 技能）
  - 与动画系统配合，实现技能的视觉效果

## 三、数据流与执行流程（详细版）

1. **初始化流程**：
   - MutanterCombatManager 初始化，加载 MutanterSkillComponent、MutanterAttackSystem 和 AttackStrategyManager
   - MutanterSkillComponent 初始化，加载技能数据和VFXManager
   - AttackStrategyManager 初始化，注册和配置攻击策略
   - SkillTriggerManager 初始化，注册所有触发器
   - SkillEffectorManager 初始化，注册所有效果
   - VFXManager 初始化，注册所有VFX控制器
   - MutanterAttackSystem 初始化，注册攻击行为

2. **主动攻击触发流程**：
   - MutanterStateMachine 检测到攻击条件
   - 调用 MutanterCombatManager.TryExecuteAttack()
   - MutanterCombatManager 检查攻击状态，调用 AttackStrategyManager 获取可用攻击策略
   - AttackStrategyManager 检查各策略的启用状态和执行条件
   - MutanterCombatManager 根据策略优先级选择最佳攻击策略
   - 如果选择技能攻击策略：
     - 调用 MutanterSkillComponent.TryExecuteSkill()
     - MutanterSkillComponent 调用 SkillTriggerManager.SelectSkill() 选择技能
     - SkillTriggerManager 执行触发器逻辑，选择最佳技能
     - MutanterSkillComponent 执行选中的技能
   - 如果选择基础攻击策略：
     - 调用 MutanterAttackSystem.TryExecuteAttack()
     - MutanterAttackSystem 选择合适的攻击行为
     - MutanterAttackSystem 执行攻击
   - MutanterCombatManager 设置攻击状态，播放动画
   - MutanterSkillComponent 通过 VFXManager 获取并激活 VFX 控制器
   - 动画完成后，MutanterSkillComponent 应用技能效果
   - MutanterSkillComponent 停用 VFX 控制器
   - MutanterCombatManager 重置攻击状态

3. **被动技能触发流程**：
   - 被动触发器（如DeathTrigger、HealthChangeTrigger）检测到触发条件
   - 调用 MutanterCombatManager.QueueSkillExecution() 添加技能执行请求
   - MutanterCombatManager.ProcessQueue() 处理技能执行
   - 锁定状态机，防止状态转换打断技能执行
   - 执行技能，播放动画和特效
   - 动画完成后，解锁状态机并处理下一个技能

4. **伤害计算流程**：
   - MutanterSkillComponent 调用 SkillEffectorManager.ApplyEffectorsBefore()
   - MutanterSkillComponent 通过 VFX 控制器获取攻击目标
   - SkillEffectorManager 应用技能效果
   - MutanterAttackSystem 执行具体的伤害计算
   - 考虑防御属性、效果状态等因素
   - 应用最终伤害到目标
   - 显示伤害数值和类型

### 8. 状态机攻击状态实现

```csharp
// 执行攻击状态
attackStates.attacking
    .Enter(smi =>
    {
        TbbDebuger.LogDebug($"[MutanterStateMachine] 进入 AttackStates.attacking");
        // 执行攻击
        bool attackSuccess = smi.ExecuteAttack();
        if (!attackSuccess)
        {
            // 攻击失败，转换到追逐状态
            if (!smi.IsStateMachineLocked)
            {
                smi.SetCurrentTarget(null);
                smi.GoTo(attackStates.chasing);
            }
        }
    })
    .Update((smi, dt) =>
    {
        // 状态机锁定时不执行状态转换
        if (smi.IsStateMachineLocked)
        {
            return;
        }

        // 检查攻击是否完成
        if (smi.CombatManager != null && !smi.CombatManager.IsAttacking)
        {
            smi.SetCurrentTarget(null);
            smi.GoTo(attackStates.chasing);
        }
    }, UpdateRate.SIM_1000ms)
    .Transition(hostile, smi => !smi.IsStateMachineLocked && smi.EmotionSMI != null && smi.EmotionSMI.INSANITYValue > smi.def.sanityThresholdToAttack)
    .Transition(incapacitated, smi => !smi.IsStateMachineLocked && smi.HealthInstance != null && smi.HealthInstance.hitPoints <= 10f)
    .Transition(attackStates.staggering, smi => !smi.IsStateMachineLocked && smi.IsStaggered)
    .Transition(attackStates.retreating, smi => !smi.IsStateMachineLocked && smi.HealthInstance != null && smi.HealthInstance.hitPoints < smi.HealthInstance.maxHitPoints * 0.3f);
```

## 五、合理性总结（实现亮点）

- **主被动同构**：逻辑高度统一，维护成本极低，扩展新技能极快
- **表现与逻辑分离**：动画、特效不影响战斗判定，适合做网络 / 同步安全
- **调度集中化**：战斗组件唯一控制时序，从根源避免冲突
- **技能可配置、可组合**：通过数据驱动的方式配置技能，不需要修改代码
- **模块化设计**：各组件职责明确，易于扩展和维护
- **反射机制**：使用反射自动注册触发器、效果和VFX控制器，减少手动配置
- **VFX抽象**：通过VFXManager统一管理特效，实现特效的标准化和可扩展性
- **攻击策略系统**：通过策略模式实现不同攻击类型的灵活配置和选择
- **技能执行队列**：确保被动技能有序执行，避免状态冲突
- **状态机锁定**：保证技能执行过程不被打断，提高系统稳定性
- **情绪监控系统**：基于多种因素计算理智值，为状态转换提供决策依据
- **多攻击类型支持**：实现了物理、心理、灵魂和侵蚀四种攻击类型
- **防御系统**：考虑物理和精神防御对伤害的影响
- **伤害可视化**：显示不同类型伤害的数值和图标

## 六、可实现性

- **极高**。所有模块都是独立职责，无循环依赖
- **不需要复杂框架**，普通状态机即可支撑
- **最小原型**：1 个触发器 + 1 个技能 + 普攻
- **平滑扩展**：后续逐步加特效、Buff、多段技能都平滑扩展

## 七、可扩展性（未来能轻松加什么）

- **更多触发器**：时间、仇恨、受击次数、区域、召唤物数量
- **更多效果**：持续伤害、吸血、护盾、变身、召唤、狂暴
- **更多表现**：多段动画、镜头震、击飞、击退、控制
- **更多策略**：技能优先级、霸体、可打断 / 不可打断
- **复杂机制**：多阶段 Boss、特殊反制、QTE、收容机制
- **攻击行为**：更多攻击类型，如远程、AOE、持续伤害等
- **AI 行为**：更智能的目标选择和攻击策略
- **VFX 效果**：更多视觉特效，如粒子效果、光线效果、爆炸效果等

## 八、已实现的核心功能

### 1. 攻击类型

- **物理攻击**（MeleeAttack）：直接造成生命值伤害
- **心理攻击**（PsychologicalAttack）：造成压力值伤害
- **灵魂攻击**（SoulAttack）：按百分比扣减生命值
- **侵蚀攻击**（ErosionAttack）：同时造成生命值和压力值伤害

### 2. 技能效果

- **基础攻击增益**（BasicAttackBounsApply）：增强基础攻击
- **伤害反射**（DamageReflection）：反射受到的伤害
- **锁血**（FrozenHitPoints）：暂时锁定生命值

### 3. 触发器

- **距离触发器**（DistanceTrigger）：根据距离触发技能
- **Berserk 触发器**（BerserkTrigger）：在特定条件下触发狂暴状态
- **生命值变化触发器**（HealthChangeTrigger）：根据生命值变化触发技能
- **死亡触发器**（DeathTrigger）：在死亡时触发技能

### 4. VFX系统

- **激光束**（LaserBeamVFXController）：直线激光攻击
- **白色激光**（FixerWhiteLaserVFXController）：白色激光攻击
- **激光横扫**（FixerWhiteLaserSweepVFXController）：240° 激光横扫
- **直线白色激光**（FixerWhiteStraightLaserVFXController）：直线白色激光攻击
- **红眼拖尾**（EyeTrailVFXController）：攻击时产生红眼拖尾特效
- **死亡伤害**（FixerRedDeathDamageVFXController）：死亡时触发的伤害效果
- **宇宙虫死亡伤害**（CosmicBugDeathDamangeVFXController）：宇宙虫死亡时的伤害效果
- **马戏团小丑死亡伤害**（CircusJokerDeathDamangeVFXController）：马戏团小丑死亡时的伤害效果

### 5. 攻击策略系统

- **技能攻击策略**（SkillAttackStrategy）：执行技能攻击
- **基础攻击策略**（BasicAttackStrategy）：执行基础攻击
- **攻击策略管理器**（AttackStrategyManager）：管理和配置攻击策略

### 6. 技能执行队列系统

- **技能执行请求**：包含技能名称、优先级、目标等信息
- **队列处理**：按优先级排序并执行技能
- **状态机锁定**：确保技能执行不被打断

### 7. 情绪监控系统

- **理智值计算**：基于环境、威胁、生物等因素
- **威胁区域可视化**：根据理智值变化显示不同颜色
- **状态转换触发**：理智值变化触发状态机转换
- **被攻击处理**：被攻击时降低理智值到攻击阈值

### 8. 状态机系统

- **攻击状态组**：包含追逐、攻击、冷却、撤退、硬直等子状态
- **目标扫描和追逐**：实现目标检测和导航
- **状态机锁定**：确保技能执行不被打断
- **受击硬直和撤退**：处理战斗中的特殊状态

## 九、性能优化建议

1. **缓存机制**：缓存常用的组件和数据，减少 GetComponent 调用
